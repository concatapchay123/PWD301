# Question Bank API (Decommissioned)

> [!NOTE]
> Các API Ngân hàng câu hỏi độc lập (`/api/questions/*`, `POST/GET /api/courses/{course_id}/questions`, `/instructor/courses/{course_id}/questions/*`) đã được thu hồi và gỡ bỏ hoàn toàn khỏi hệ thống PWD301.
>
> Việc tạo và quản lý câu hỏi hiện được thực hiện thông qua Assessment / Exam Authoring API:
> - `POST /instructor/assessments/{assessment_id}/questions/create`
> - `POST /instructor/assessments/{assessment_id}/questions/batch`
> - `PUT /instructor/assessments/{assessment_id}/questions/{question_id}`
> - `DELETE /instructor/assessments/{assessment_id}/questions/{question_id}`
> - `POST /instructor/assessments/{assessment_id}/questions/reorder`
