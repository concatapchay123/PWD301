# Non-Negotiable Invariants

1. No JWT in localStorage for website AJAX.
2. Suspended/deactivated User cannot continue active session/JWT.
3. Role is not enough; authorize the concrete resource.
4. One active EnrollmentPeriod per Student/Course logical Enrollment; capacity/prerequisite are race-safe.
5. Prerequisite cycles forbidden; active dependency blocks archive/delete.
6. Exposed/graded QuestionRevision is historical and retained.
7. Question type cannot change after a Student has answered.
8. Attempt snapshot is immutable historical evidence.
9. Server time is authoritative; close time is hard boundary.
10. One active editing lease; stale owner takeover keeps same Attempt.
11. Late/stale offline answer cannot overwrite newer or pass deadline.
12. Submit is idempotent; one logical result.
13. Assessment timing locked after publish.
14. Assessment structure/assigned points locked after first Student start.
15. Legitimate Question corrections remain possible through revision/regrade.
16. Grade/result changes append history; historical answers/snapshots not rewritten.
17. Detail purge after >30 days no-rejoin excludes that period from future regrade but preserves compact completion/prerequisite summary.
18. Unsafe/unscanned files cannot activate; scanner failure is fail-closed; strict 50MB non-archive attachment policy (archives .zip/.rar/.7z strictly forbidden); video <1 GB.
19. FileAsset has at most one ACTIVE revision; shared blob deletion respects references/recovery.
20. RAG retrieves only currently authorized published content; archived/deleted/draft excluded.
21. Raw AI chat content purges after five minutes inactivity.
22. Important audit is append-only; required-audit sensitive action fails if audit cannot persist.
23. Admin override is explicit, reasoned and notified where required; no impersonation.
24. No broad cascade deletion of historical learning/assessment data.
25. Video Protection & YouTube Standard 16:9 Player: Enrolled students cannot download raw lesson video files (.mp4/.webm); all internal playback is served via encrypted HLS (AES-128) with 12-hour (43,200s) DRM key token lifespan matching active student session. YouTube Standard 16:9 Player uses standard 16:9 full responsive viewport (100% width, 100% height, zero crop, preserving all video details) across all 4 touchpoints: Student learning view (primary and supplementary videos), Instructor preview modal (`openVideoModal`), Course Hero intro trailer (`#course-hero-media-box`), and Admin Review modal/pane (`renderReviewerCoursePreview`). Mandatory Cover Poster/Backdrop Shield conceals the player before user play interaction (revealing video only upon `PLAYING` state), with zero YouTube branding. Single event listener invariant eliminates duplicate onclick/addEventListener conflicts. `YT.Player` uses `youtube-nocookie.com` without conflicting `origin` parameter, eliminating Error 153. Resilient Playback Fallback: if YOUTUBE_API_KEY is not configured or Google Data API encounters issues, backend gracefully falls back to 3-tier duration fallback (oEmbed / client reported duration / lesson duration / safe default 1800s, min 300s) without raising LessonValidationError to block students, and reconciles duration on the first heartbeat. Visible watermark overlays on video and seek-lock indicator badges are eliminated from UI. Pacing Engine & 5-Second Seek Unlock: Anti-forward seek restriction is strictly enforced from 00:00 up to (Duration - 5s). When video reaches the final 5 seconds (currentTime >= Duration - 5s, or video duration <= 5s), the system automatically credits video completion (`is_video_complete = true`, `unlocked = true`) and allows free scrubbing through the last 5 seconds to duration. Realtime Lesson Completion Gate (No F5 Reload): Lessons evaluate completion upon video end (`onEnded` event on YouTube state 0 and HTML5 ended) and miniquiz completion; Next button dynamically transitions from disabled gray (`bg-slate-200 text-slate-400 cursor-not-allowed`) to active emerald green (`bg-emerald-600 text-white cursor-pointer animate-fade-in`) and sidebar outline unlocks next lesson without requiring page refresh (F5). Lesson completion strictly requires accumulated wall-clock heartbeat time on the server.

The Next button is gray/disabled (bg-slate-200 text-slate-400 cursor-not-allowed) when incomplete, and transitions to emerald green/enabled (bg-emerald-600 text-white cursor-pointer) when complete.

Course Deletion & Lifecycle RBAC: Instructors may permanently delete (Hard Delete) their own unpublished courses (`status == 'DRAFT'` and `published_at is None`), cascade-purging associated draft units, lessons, and resources. Instructors manage appeals via dedicated Topbar navigation (`#/instructor/appeals`), organized by Course -> Chapter -> Lesson. Instructor regrading inputs the direct final score (replacing prior score, appending to `AssessmentResultHistory`), provides feedback, and dispatches an automated notification to the student.
