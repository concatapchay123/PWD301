# Course Lifecycle

Draft creation → Instructor content authoring → review request → Admin approve/publish → Published updates via unified Course Changeset (isolated working draft → single atomic submit → Admin side-by-side diff review & atomic approve/reject) → archive/trash/recovery. Fragmented or piecemeal per-lesson approvals are strictly banned. Reassignment never deletes Course. Archive/delete precheck blocks active prerequisite dependency. Courses with Student history preserve historical records.
