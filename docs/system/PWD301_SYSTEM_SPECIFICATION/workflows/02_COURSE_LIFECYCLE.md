# Course lifecycle

The [replacement contract](../implementation/WORKFLOW_SUPERSESSION.md) is normative.
Never-approved DRAFT -> direct validated authoring -> initial submission (frozen)
-> approve/publish or reject/withdraw to authoring. After first approval every
legal edit goes into exactly one COURSE_VERSION_CHANGESET/DRAFT; submit seals
it -> atomic version-bound approval or reject/withdraw with a complete successor
draft. Students always receive the approved baseline. Archive/recovery preserves
the review boundary, active prerequisite dependencies and historical records.
