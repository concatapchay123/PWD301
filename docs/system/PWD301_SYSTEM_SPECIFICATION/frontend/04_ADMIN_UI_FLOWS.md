# Admin UI Flows

Course review/approval (initial publish review and atomic 3-Category Visual Diff review: Course Metadata, Lesson Content & Media, Curriculum Changeset with collapsed unchanged fields and inline highlight) → user role/suspension/reassignment → reasoned override → audit/notification. Review queues feature standardized [Xem] (inspect) first and [Duyệt] (quick pass with confirmation modal) second; detail review enforces [Từ chối] (reason >= 5 chars + confirm) and [Phê duyệt] (confirmation modal before apply). Fragmented 3-field diffs and generic 'Thay đổi khác' fallbacks are permanently decommissioned. System operations include storage/scanner/Gemini/worker/DB/backup health, alerts, class gradebook PDF export, and manual backup/restore. Sensitive actions use a dedicated confirmation form requiring reauthentication, exact phrase and reason. No impersonation action exists.

TASK-090 preview uses the same read-only chapter/lesson tree and full lesson workspace as instructor preview. Proposed content and resource attach/detach operations are overlaid without mutating the original lesson. Preview alone performs no persistence or learner progress action. Approval/rejection is persisted with mandatory audit in one caller-owned transaction; concurrent reviewers serialize on the course and request rows. Invalid payloads, missing resources and invalid transitions return business errors. The queue refreshes from backend results after a decision, without requiring a page reload. Preview does not grant raw-video access to students or administrators without course-review permission.
