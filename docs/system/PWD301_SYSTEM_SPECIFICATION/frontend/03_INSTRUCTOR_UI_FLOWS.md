# Instructor UI Flows

Course create/edit → Single-Page Curriculum Studio (Curriculum Tree on left, Vertical Block Editor on right with Text, Video, Document, and Quiz blocks) → Assessment builder/blueprint validation → publish → Published Course Working Draft (isolated changes staged locally, Sticky Draft Action Bar with atomic submit, fail-closed edit lock during Admin review) → monitor attempts → manual essay grading → correction/regrade status → dashboard/export. UI visibly disables editing while changeset is pending review. Separate fragmented Lesson Studio and per-lesson approval requests are permanently decommissioned.

TASK-090 reviewer preview reuses the course tree: chapters and lessons on the left, the selected lesson workspace on the right (stacked on narrow screens). Switching lessons pauses removed media immediately. Markdown, authorized attachments and local quiz feedback are available without student pacing; preview never creates a lesson, playback session, progress or completion record. Multiple-choice, fill-blank and matching quizzes use their canonical answer metadata; local feedback is not a grading submission. Uploaded video uses the authenticated reviewer stream endpoint and retains object/revision/scan authorization. Closing preview releases media and temporary document URLs. A browser without a native PDF viewer retains an explicit download fallback.
