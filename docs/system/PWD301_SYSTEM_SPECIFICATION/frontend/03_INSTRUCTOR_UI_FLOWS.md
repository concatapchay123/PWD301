# Instructor UI Flows

Course create/edit → Single-Page Curriculum Studio (curriculum tree and block editor) → initial submission → Admin approval → course publication. Before initial submission, save directly. After first approval, save every legal change to the one server-persisted aggregate draft; reload projects that saved draft. Submit once for atomic review. Both initial and update submissions freeze editing; withdraw the displayed version before continuing. Rejection and withdrawal preserve the complete proposal. See the [replacement contract](../implementation/WORKFLOW_SUPERSESSION.md).

The landing editor groups course prerequisites under Cài đặt & Học vụ. The shared 1280×720 cover crop renders at 16:9 in editing, discovery, enrollment and Admin review. Assessment configuration exposes detail-result visibility separately from score-release policy. Instructor matching preview and learner answering share the board renderer/controller; active learner attempts never receive preview correctness.

TASK-090 reviewer preview reuses the course tree: chapters and lessons on the left, the selected lesson workspace on the right (stacked on narrow screens). Switching lessons pauses removed media immediately. Markdown, authorized attachments and local quiz feedback are available without student pacing; preview never creates a lesson, playback session, progress or completion record. Multiple-choice, fill-blank and matching quizzes use their canonical answer metadata; local feedback is not a grading submission. Uploaded video uses the authenticated reviewer stream endpoint and retains object/revision/scan authorization. Closing preview releases media and temporary document URLs. A browser without a native PDF viewer retains an explicit download fallback.
