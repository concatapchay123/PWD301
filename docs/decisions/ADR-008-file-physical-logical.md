# Physical Blob and Logical FileAsset Separation

**Status:** Accepted / derived from confirmed project rules.

## Decision

Content-hash deduplicated physical blobs are separated from logical assets/revisions/references.

## Why

Supports deduplication, quarantine/replacement/recovery and safe lifecycle management.
