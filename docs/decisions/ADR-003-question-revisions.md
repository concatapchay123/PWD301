# QuestionRevision for Used Questions

**Status:** Accepted / derived from confirmed project rules.

## Decision

Used questions create immutable historical revisions for important edits; choices belong to the revision.

## Why

Allows corrections without rewriting what students saw and supports regrading/audit.
