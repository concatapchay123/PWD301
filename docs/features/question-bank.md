# Question Bank (Decommissioned)

> [!NOTE]
> Phân hệ "Ngân hàng Câu hỏi" (Question Bank Hub) độc lập đã được gỡ bỏ hoàn toàn khỏi hệ thống (cả backend API endpoints và frontend navigation/views).
> Việc biên soạn câu hỏi khảo thí hiện được thực hiện trực tiếp bên trong từng bài thi thông qua **Studio Soạn đề thi (Exam Studio)** (`POST /instructor/assessments/<id>/questions/create`, `batch`, `.docx` parser).
> Các bảng cơ sở dữ liệu `questions`, `question_revisions`, `question_revision_choices`, `question_revision_accepted_answers`, và `question_provenance` được bảo lưu để phục vụ mô hình câu hỏi bài thi và bảo toàn hợp đồng CSDL 73 bảng chuẩn MS SQL Server.
