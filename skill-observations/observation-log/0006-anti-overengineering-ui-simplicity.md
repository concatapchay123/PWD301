**Issue:** Agents repeatedly added complex animations (liquid spring physics, screen-flickering transitions), redundant navigation bars, nested card layouts, and overwhelming academic metadata that confused non-technical users and created interface clutter.

**Suggested improvement:** Codify the core product design rule: 'Backend có thể phức tạp. Frontend phải đơn giản.' Remove unnecessary animations, eliminate duplicate menu items, hide internal IDs, keep topbars centered and clean, and present intuitive actions without requiring a user manual.

**Principle:** Code and UI that don't need to exist are the best code and UI; user-facing simplicity must always take precedence over decorative agent complexity.
