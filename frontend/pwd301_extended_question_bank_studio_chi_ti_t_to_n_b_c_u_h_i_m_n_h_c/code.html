Trong kiến trúc RESTful API xây dựng với Python (FastAPI/Django), tại sao mô hình Stateless Authentication bằng JSON Web Token (JWT) lại được ưu tiên sử dụng thay vì Stateful Session trên máy chủ trong các hệ thống Microservices quy mô lớn?

A JWT tự động mã hóa bí mật dữ liệu payload nên an toàn tuyệt đối ngay cả khi truyền tải qua giao thức HTTP không mã hóa.
B
JWT tự chứa thông tin xác thực (Self-contained), giúp máy chủ xác minh chữ ký mã hóa không phụ thuộc vào bộ nhớ tập trung (Redis/Session Store), tối ưu hóa khả năng mở rộng ngang (Horizontal Scaling). check_circle
Chuẩn trích dẫn: RFC 7519 & Giáo trình PWD301 Chương 4.3 (FastAPI OAuth2 Bearer).
C Máy chủ có thể thu hồi (Revoke) ngay lập tức một JWT bị lộ mà không cần truy vấn bất kỳ danh sách đen (Blacklist) hay cơ sở dữ liệu nào.
D Kích thước của chuỗi JWT luôn nhỏ hơn 32 bytes nên giúp tiết kiệm 95% băng thông mạng so với Cookie Session truyền thống.
