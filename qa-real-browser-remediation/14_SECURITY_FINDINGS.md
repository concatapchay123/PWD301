# 14. SECURITY & ACCESS CONTROL FINDINGS

- **Two-Tier RBAC:** Strict separation of Student, Instructor, Admin Primary, Financial, and Monitoring.
- **Anti-Tamper Blackout Shield:** Confirmed session revocation and screen blackout upon DevTools intrusion.
- **Fail-Closed File Quarantine:** Unscanned and quarantined files inaccessible to student downloads.
